# Barato Vinil

Site estático (HTML + CSS + JS, sem build).

- `index.html`: página inicial
- `app.js`: catálogo de discos e filtros. Edite a lista `CATALOGO` para trocar discos, preços (`preco`) e links de associado da Amazon (`link`).
- `img/guia.webp`: imagem de fundo do card do guia

Publicar no GitHub Pages: suba estes arquivos na raiz do repositório e ative em Settings › Pages › Deploy from a branch (main, /root). Para usar baratovinil.com.br, informe o domínio em "Custom domain" e aponte o DNS para o GitHub Pages.
